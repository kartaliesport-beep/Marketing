## Versioning Policy

Marketing uses:

```
MAJOR.MINOR.PATCH
```

Example:

```
1.0.0
```

Meaning:

* **MAJOR** — Breaking changes.
* **MINOR** — New features without breaking compatibility.
* **PATCH** — Bug fixes and small improvements.
